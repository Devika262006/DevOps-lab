# Experiment 7 - Building a Simple Application using Gradle

## Aim

To install and configure Gradle, create a simple Java application using Gradle, define the build configuration, and build and run the application.

## Tools Used

- JDK 21
- Gradle 9.8.0
- Command Prompt
- Windows 11

## Project Structure

Experiment-7-Gradle/
  settings.gradle
  build.gradle
  README.md
  src/main/java/com/example/App.java

## Gradle Commands

gradle -version
gradle clean
gradle build
gradle run
gradle tasks
gradle jar

## Application Output

Hello from Gradle!

## Result

Thus a simple Java application was created using Gradle, the build configuration was defined, the application was compiled and packaged successfully, and the program output was verified.
